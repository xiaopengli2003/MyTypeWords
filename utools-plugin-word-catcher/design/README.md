# 正式界面预览

v1.0.0 使用“雾白墨蓝”：墨蓝主色、灰白背景和浅蓝选中状态。预览直接使用正式 app.js、style.css 和 Logo，不加载配色覆盖。旧候选配色和临时截图已清理。

运行 `npm run preview`，打开输出的本机地址。`current.html` 默认展示 800×620 内容区，可切换 720、640、480 宽和 620、544、480 高；尺寸控制位于预览框外，不进入产品界面。可用环境变量 `TYPEWORDS_PREVIEW_PORT` 固定端口。

`demo.js` 在 iframe 中提供隔离的演示词库与服务。生成和保存仅操作内存，刷新即重置；文件与备份按钮不访问真实文件，网络请求不调用真实 API。服务器仅允许读取预览必要文件，不暴露个人配置或数据目录。

设计取舍：背景衬托内容，主色用于操作和选中状态；减少重复标题与说明，必要的目录迁移、同名合并、配置替换和 Key 提示保留。设置内容独立滚动，保存栏仅在修改或错误时出现，模型菜单随空间向上或向下展开。

Logo 正式文件为 `../logo.png`（256×256），高清原稿和生成记录在 `../assets/source/`。
