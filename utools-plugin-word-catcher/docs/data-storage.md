# 数据目录与首次使用

## 默认即可使用

新安装不需要选择目录。插件通过 `utools.getPath('documents')` 获取本机系统文档目录，默认使用它下面的 `MyTypeWords/typewords-data`。旧宿主不支持该接口时回落到用户主目录下的 Documents。

- macOS 常见位置：`~/Documents/MyTypeWords/typewords-data`。
- Windows 常见位置：`C:\Users\用户名\Documents\MyTypeWords\typewords-data`；系统文档目录重定向到 OneDrive 或其他磁盘时，跟随系统设置。
- 路径不写死为开发者电脑的路径，也不存放在插件安装包内。

用户只需先配置 AI 服务。首次保存设置自动创建数据结构；未保存过设置时，「打开目录」也会创建空的 daily、prompts 目录并直接打开文件夹。目录初始化不覆盖已有配置或提示词。

若默认目录无法写入，保留输入与词库，显示失败原因；用户可以在“数据与导出”里选择可写目录后保存。旧配置迁移失败也允许进入设置，不让用户卡在空白页。

## 目录结构

```text
MyTypeWords/
└── typewords-data/
    ├── config.json
    ├── daily/
    │   ├── 2026-10-08.json
    │   └── 2026-10-09.json
    └── prompts/
        └── system-prompt.md
```

| 位置                     | 用途                                          | 是否建议手动编辑                       |
| ------------------------ | --------------------------------------------- | -------------------------------------- |
| config.json              | 多套服务的地址、Key、模型、思考模式及目录信息 | 优先用设置页；文件含明文 Key           |
| daily/YYYY-MM-DD.json    | 直接导入 TypeWords 的词条数组                 | 当天会由插件重建，优先编辑插件里的词条 |
| prompts/system-prompt.md | 自定义生成规则                                | 可以编辑，保留输出 Schema              |
| uTools 本地库            | 完整词条、采集原文、创建和更新日期、设置镜像  | 用插件和备份入口管理                   |

保持扁平目录便于用户理解，不按月再建子目录；文件名已有完整日期，排序和历史管理足够明确。开发截图、演示数据、源码和依赖不放进用户数据目录。没有语音缓存或自动备份功能，因此不预先创建空的 audio、cache、backups 目录。

当天文件只包含当天创建的词条，保存、编辑和删除时同步重建；历史文件作为存档保留，编辑旧词不改写旧文件。历史存档不能代替完整词库备份，因为它不含采集元信息，也可能已不同于当前词库内容。

## 更换目录

在“设置 → 数据与导出”选择目录或填写本机绝对路径，保存后生效。可以选择一个专用空文件夹，不需要预先手动创建子目录。

更换目录会在新位置建立配置、当天文件和默认提示词，原文件保留；**不会自动复制历史导出和旧提示词**。需要完整迁移时，先导出词库，再在新目录合并该备份。目录指向已有数据文件夹时，已有提示词不会被默认内容覆盖。

未保存的目录只属于设置草稿；查看文件、导出和恢复仍使用已保存的目录。Windows 支持盘符和 UNC 路径，macOS 使用本机绝对路径。

## 换电脑与备份

1. 原电脑分别「导出词库」和「导出配置」。
2. 新电脑安装插件，沿用默认目录或选择本机目录并保存。
3. 「合并词库」恢复词条与存档；「替换配置」恢复 AI 服务，保留新电脑目录。

仅复制插件源码不会迁移 uTools 本地词库；仅复制数据文件夹也不等于完整迁移。词库备份包含采集原文与日期，服务配置单独导出，避免分享词条时带上 Key。

v1.0.0 不自动备份，也不搬移已有数据；以后新增缓存时应优先使用宿主专用本地或临时目录，而不混入 daily 导出。此处的文档目录是用户需要直接找到和导出的文件位置。

接口依据：[系统路径、目录选择与打开文件夹](https://next.u-tools.cn/docs/api-reference/system.html)。
