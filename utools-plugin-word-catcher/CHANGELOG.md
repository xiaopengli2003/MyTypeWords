# 变更记录

## 1.0.0 — 2026-10-09

首个正式版本。

- 划词或手动输入单词、短语和句子，调用 OpenAI 兼容服务生成 TypeWords 词条。
- 编辑音标、释义、例句及完整 JSON；已有词更新保留创建日期，重命名冲突不覆盖。
- 全部词库按创建日期折叠分组，支持跨日期搜索、历史存档恢复。
- 多套服务配置、模型列表刷新和搜索选择、连接测试与可选思考模式。
- 系统文档目录默认存储，首次保存自动建立目录、每日导出与提示词。
- 完整词库合并恢复与服务配置替换，保留本机数据目录，写入失败尝试回退。
- 雾白墨蓝主题、256×256 Logo、小窗口布局、精简文案与按需保存栏。
- 主窗口退出后回到 uTools，兼容分离窗口和原生对话框分支。
- 修复 UTF-8 响应分片乱码、响应中断悬挂、删除失败缺少反馈及配置导出非原子写入。
- 统一格式规范，测试与运行代码分目录，提供验证、隔离预览及发布构建命令。

验证范围包含 Node 20.19.1 回归、模拟 Win/Mac 平台分支与浏览器布局；完整原生宿主验收边界见 [兼容性说明](docs/compatibility.md)。朗读仅调研，未进入本版本。
